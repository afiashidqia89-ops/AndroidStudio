Tweak build.prop

Koleksi properti sistem untuk performa, baterai, dan tampilan.

Cara menerapkan: tanpa root — sebagian bisa via adb shell setprop; dengan root — edit build.prop lewat MT Manager/Root Explorer, atau resetprop (Magisk). Paling aman lewat modul Magisk agar mudah dibalik.
Wajib dibaca: sebagian tweak adalah warisan era lama dan diabaikan Android modern. Uji satu per satu; nilai yang salah bisa bootloop — catat nilai asli sebelum mengubah.

Tentang

DroidForge v1.0 — toolkit modifikasi Android berbentuk satu file HTML. Berjalan offline, tanpa izin, tanpa server. Alat bantu edukasi; gunakan dengan bijak dan tanggung jawab sendiri.

APK Modding

Etika dulu: gunakan untuk memodifikasi APK milik sendiri atau open-source — belajar, terjemahan, tema. Membajak aplikasi berbayar itu pelanggaran hukum.
Penting: APK hasil mod bertanda tangan berbeda → uninstall versi asli dulu (data aplikasi hilang). APK split/bundle harus di-merge jadi satu dulu (ApkEditor / NP Manager).
Perangkat Lunak
01
apktool

Standar de-facto dekompilasi & build ulang APK (resource + smali) di PC.

02
MT Manager

Editor serba-bisa di HP: smali, resource, editor teks, penandatangan.

03
NP Manager

Alternatif MT Manager; kuat untuk split-merge & XML.

04
ApkEditor

CLI untuk merge split APK menjadi satu APK utuh yang mudah diedit.

05
jadx

Mengubah APK menjadi kode Java terbaca — pas untuk analisis logika.

06
zipalign + apksigner

Duo wajib dari Android build-tools untuk finalisasi & tanda tangan.

Alur Kerja apktool
1
Siapkan Java 17+

apktool butuh Java. Cek instalasinya:

java -version
2
Dekompilasi

Ubah APK menjadi folder resource + smali:

apktool d aplikasi.apk -o folder
3
Edit isi APK

Teks & terjemahan di res/values/strings.xml, tampilan di res/layout, ikon di res/mipmap-*, logika di smali/.

4
Build ulang

Kemas kembali menjadi APK:

apktool b folder -o mod.apk
5
Align

Ratakan memori agar terpasang mulus:

zipalign -p -f 4 mod.apk mod-aligned.apk
6
Tanda tangani

Buat keystore di generator di bawah, lalu:

apksigner sign --ks kunci.jks --out mod-final.apk mod-aligned.apk
Generator Keystore
Buat kunci tanda tangan

Sekali buat, simpan selamanya — dipakai untuk semua update mod kamu.


 

 
File .jks + password = identitas aplikasimu. Hilang = tidak bisa update APK mod yang sama.

 
Tips & Jebakan

 
Gagal install: "App not installed"
Tanda tangan berbeda → uninstall APK asli dulu. Masih gagal? Cek arsitektur (arm64-v8a) dan versi Android minimum dari mod kamu.

 
APK split / bundle dari Play Store
Berkas .apkm/.xapk/.apks berisi beberapa APK. Merge dulu: java -jar ApkEditor.jar m -i nama.apkm atau lewat NP Manager.

 
Aplikasi mendeteksi mod
Gunakan LSPatch untuk menyematkan modul tanpa mengubah APK, atau modul hide pada LSPosed.

 
Smali terlalu rumit?
Mulai dari resource: ubah warna, teks, layout, ikon. Smali = bytecode; edit hanya jika paham struktur invoke-method.







 
Root & Magisk

 
Risiko nyata: garansi hangus, aplikasi bank & dompet digital bisa menolak (Play Integrity), dan satu langkah salah bisa bootloop. Baca bagian Pemulihan sampai paham sebelum mulai.

 
Prasyarat

 
01
Bootloader bisa dibuka
Samsung/Xiaomi/Google/OnePlus: bisa. Sebagian merek/operator memblokir permanen. Xiaomi butuh akun resmi & masa tunggu.

 
02
boot.img persis versi firmware
Ambil dari firmware dengan versi sama persis. ROM streaming (payload.bin) diekstrak dengan payload-dumper-go.

 
03
PC + fastboot + kabel data bagus
platform-tools terpasang (lihat Setup ADB). Backup semua data — unlock menghapus seluruh isi HP.

 
Alur Root Magisk

 
1
Masuk mode bootloader

 
adb reboot bootloader

 
2
Buka bootloader
Konfirmasi di layar HP dengan tombol volume. SEMUA DATA TERHAPUS.

 
fastboot flashing unlock

 
3
Salin boot.img ke HP
Letakkan di folder Download.

 
4
Patch lewat Magisk
Instal aplikasi Magisk → Install → Select and Patch a File → pilih boot.img → hasilnya magisk_patched-xxxxx.img di Download.

 
5
Tarik hasil patch ke PC

 
adb pull /sdcard/Download/magisk_patched-xxxxx.img .

 
6
Flash boot yang dipatch

 
fastboot flash boot magisk_patched-xxxxx.img

 
7
Restart & verifikasi
Buka aplikasi Magisk — status Installed berarti root aktif.

 
fastboot reboot

 
Aktifkan Zygisk di Magisk → Pengaturan agar modul Shamiko & LSPosed bisa berjalan.

Pemulihan Bootloop

 
1 · Magisk Safe Mode
Tekan & tahan Volume− saat logo boot muncul → semua modul otomatis nonaktif → hapus modul bermasalah di aplikasi Magisk.

 
2 · Flash boot stok
Masih gagal? Kembalikan boot.img asli firmware:
fastboot flash boot boot.img

 
3 · Pulihkan total
Flash firmware penuh lewat alat resmi merek masing-masing (ODIN untuk Samsung, SP Flash untuk MediaTek, Mi Flash untuk Xiaomi). Data tetap terhapus.

 
Sebelum update OTA: buka Magisk → Uninstall → Restore Images dulu, baru update; setelah itu patch ulang boot.img yang baru.







 
Setup ADB

 
1 · Aktifkan Debugging di HP

 
01
Buka Opsi Pengembang
Pengaturan → Tentang ponsel → ketuk Nomor build 7 kali (Xiaomi: ketuk Versi MIUI/HyperOS).

 
02
Nyalakan USB Debugging
Pengaturan → Sistem → Opsi pengembang → USB debugging.

 
03
Sambungkan kabel
Pilih mode Transfer file saat notifikasi USB muncul.

 
04
Izinkan kunci RSA
Popup "Izinkan debugging USB?" di HP → centang Selalu izinkan → OK.

 
2 · Pasang ADB di PC

 
W
Windows
Unduh platform-tools dari developer.android.com → ekstrak ke C:\platform-tools → buka CMD di folder itu.

 
M
Mac

 
brew install android-platform-tools

 
L
Linux

 
sudo apt install adb

 
05
Uji koneksi
Daftar berisi serial + kata device = sukses.

 
adb devices

 
3 · Debugging Nirkabel (Android 11+)

 
01
Aktifkan Debugging nirkabel
Opsi pengembang → Debugging nirkabel → Pairing device dengan kode.

 
02
Pair & sambung
Perintah lengkapnya ada di ADB Builder → Koneksi. Keunggulan: bebas kabel, asal satu jaringan WiFi.

 
Masalah Umum

 
Status "unauthorized"
Cek layar HP → izinkan popup RSA. Kalau popup tak muncul: cabut-pasang kabel, matikan-nyalakan USB debugging, atau adb kill-server lalu ulangi.

 
"no devices" terdeteksi
Ganti kabel/port USB, pastikan mode Transfer file aktif. Windows: pasang driver OEM (Google USB Driver / driver merek).

 
"adb" bukan perintah internal
Jalankan CMD dari folder platform-tools, atau tambahkan foldernya ke PATH Windows.

 
Ada beberapa perangkat tersambung
Tentukan target dengan serial: adb -s SERIAL shell ... (lihat serial di adb devices).
