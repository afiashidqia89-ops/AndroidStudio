Kesiapan Build

    Cara Build — 100% di HP (Termux)

    Tanpa laptop, tanpa GitHub, tanpa akun apa pun. Termux (aplikasi terminal gratis) mengompilasi proyek ini menjadi APK sungguhan di HP Anda memakai rantai perkakas resmi Android: aapt → ecj → d8 → apksigner.

    Pasang Termux (sekali saja). Unduh dari F-Droid — jangan versi Play Store (tidak lagi dirawat).

    Buka halaman Termux di F-Droid

    Buka Termux, izinkan akses penyimpanan:

    termux-setup-storage

    Unduh paket proyek dari aplikasi ini:

    File bernama proyek.zip masuk ke folder Download.

    Salin satu perintah ini ke Termux lalu tekan Enter (mengekstrak + membangun):

    Tunggu 3–10 menit (pertama kali: memasang perkakas + mengunduh android.jar ±35 MB, sekali saja; build berikutnya jauh lebih cepat & bisa offline).

    Selesai → APK muncul di folder Download dengan nama app.apk.

    Buka File Manager → Download, ketuk APK, izinkan “instal aplikasi tidak dikenal”, pasang. Selesai — aplikasi AI Anda kini APK sungguhan!

    Perintah Penting Lain

    Build ulang setelah mengubah kode di aplikasi ini

    Unduh ZIP terbaru dulu, lalu:

    cd ~/dfapp && bash build.sh

    Android.jar gagal terunduh? Unduh manual

    Unduh android.jar (±35 MB)

    Lalu taruh di: Internal/Android/data/com.termux/files/home/dfstudio/android.jar

    Alternatif: Build via GitHub Actions

    Tidak mau pasang Termux? Unduh repo siap-push ini, unggah ke GitHub, dan Actions yang membangun APK-nya (butuh akun GitHub gratis + internet). Hasilnya APK debug yang langsung bisa dipasang.

    Buka github.com/new → beri nama repo bebas (Public) → Create repository.

    Di halaman repo: klik “uploading an existing file” → seret seluruh isi ZIP ini (folder .github WAJIB ikut — aktifkan tampilan file tersembunyi di File Manager) → Commit changes.

    Tab Actions → tunggu “Build APK” selesai (±3–5 menit) → klik run teratas → Artifacts → unduh APK → ekstrak & pasang.

    Update: ubah kode di sini → unduh ZIP repo lagi → upload ulang (ganti file) → Actions jalan lagi. Naikkan versionCode dulu agar bisa dipasang di atas versi lama.

    Yang Perlu Diketahui

    • Kunci tanda tangan dibuat otomatis di ~/dfstudio/dfstudio.keystore — jangan hapus, agar update aplikasi terpasang tanpa uninstall.
    • APK bertanda tangan sendiri (self-signed): pas untuk dipakai sendiri / dibagikan langsung, bukan untuk Play Store.
    • Semua proses lokal: kode Anda tidak dikirim ke mana pun.

    Alur Kerja: AI → APK

    1. Minta kode ke AI — pakai tombol “Buat Prompt AI” di bawah, tempel ke Z.ai/ChatGPT/Claude, dapatkan kode.
    2. Impor — tab Kode → “Tempel Kode AI” atau impor file/ZIP.
    3. Cek Pratinjau — pastikan tampilannya benar.
    4. Build — unduh ZIP proyek, jalankan satu perintah di Termux, pasang APK-nya.

    Buat Prompt untuk AI

    Tanya Jawab

    Apakah benar-benar tidak perlu GitHub / laptop?

    Benar. ZIP proyek dibangun oleh Termux di HP Anda sendiri. Internet hanya dipakai sekali di awal untuk memasang perkakas (aapt, ecj, d8, apksigner, openjdk) dan mengunduh android.jar ±35 MB. Setelah itu build berikutnya bisa sepenuhnya offline.

    Build gagal / berhenti di tengah, bagaimana?

    Baca baris merah paling akhir. Masalah paling umum: (1) storage belum diizinkan — jalankan termux-setup-storage; (2) jaringan lambat saat unduh android.jar — jalankan ulang bash build.sh, unduhan dilanjutkan dari awal tapi perkakas tidak dipasang dua kali; (3) kehabisan ruang — butuh ±600 MB bebas.

    APK tidak bisa dipasang: “App not installed”

    Biasanya bentrok tanda tangan: sebelumnya Anda memasang APK dengan nama paket sama tapi kunci berbeda. Uninstall versi lama dulu. Pastikan juga versi Android minimal 7.0 (API 24).

    Cara mengganti ikon / nama / warna?

    Tab Proyek. Setelah berubah, unduh ulang ZIP proyek dan build ulang. Nama paket JANGAN diubah jika ingin memperbarui aplikasi yang sudah terpasang (anggap itu identitas tetap).

    Cara mengirim APK ke orang lain?

    File APK di folder Download bisa dikirim via WhatsApp/Telegram/email seperti file biasa. Penerima tinggal mengetuk dan mengizinkan instalasi.

    Aplikasi AI saya butuh file pendukung (gambar/JS/CSS)

    Impor ZIP berisi seluruh file ( struktur folder dipertahankan), atau impor file satu per satu di tab Kode. Semua ikut masuk ke assets/www/ di APK.

    Zona Berbahaya

    Mengembalikan contoh proyek awal. Unduh dulu ZIP proyek jika masih diperlukan.
